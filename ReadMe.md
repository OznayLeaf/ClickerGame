# Tkinter Clicker Game

A basic desktop clicker game built with Python and Tkinter.

## Overview
I built this project to get comfortable with basic Python syntax, state management (tracking numbers with variables), and the fundamentals of event-driven GUIs. Clicking the button increments the score displayed on the screen.

## What I Learned
- **Python Syntax:** Functions, global/local variables, and conditional logic.
- **Tkinter Basics:** Creating a main window, adding labels and buttons, and updating text on click events.
- **Git Basics:** Initializing a repository and pushing local code to GitHub.

## How to Run

1. Clone the repository:
   git clone https://github.com/OznayLeaf/ClickerGame.git
2. Run the script:
   python main.py
